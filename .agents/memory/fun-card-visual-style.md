---
name: Fun card visual style
description: Visual direction for IBEKS .cardp and .cardw cards.
---

The IBEKS Fun cards use a 1280×720 futuristic ID-card composition: dark angular background, neon male/female palette, large circular profile photo on the right, left-side identity rows, and a footer with quote, logo, barcode, and QR.

**Why:** The user explicitly wants the uploaded black-neon reference composition while keeping existing commands, data, and other plugins unchanged.

**How to apply:** Future card changes should stay isolated to the Fun card generator and preserve `.cardp`/`.cardw` behavior, weekly deterministic values, and Telegram avatar fallback.
