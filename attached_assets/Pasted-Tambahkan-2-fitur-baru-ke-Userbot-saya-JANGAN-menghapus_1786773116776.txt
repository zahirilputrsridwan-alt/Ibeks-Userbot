════════════════════════════
FITUR 1 — PM CONTROL
════════════════════════════

Buat command:

.pm all
.pm contacts
.pm nobody

Fungsi:

1. `.pm all`
   - Semua orang boleh mengirim PM.
   - Tidak ada auto-reply penolakan.

2. `.pm contacts`
   - Hanya orang yang ada di kontak yang boleh mengirim PM.
   - Jika bukan kontak, otomatis kirim pesan penolakan.

3. `.pm nobody`
   - Semua PM dari orang lain ditolak.
   - Owner/Sudo sesuai permission system tetap dikecualikan.

PENTING:
- Hanya berlaku di private chat.
- Tidak boleh aktif di grup.
- Setting harus tersimpan setelah restart.
- Jangan membuat reply loop/spam.
- Jangan merusak handler PM yang sudah ada.


════════════════════════════
CUSTOM PM REJECTION MESSAGE
════════════════════════════

Tambahkan command:

.pmmsg set <pesan>
.pmmsg status
.pmmsg reset

Contoh:

.pmmsg set 🚫 Jangan chat saya dulu, sedang sibuk bro 😴

Maka ketika PM ditolak, Userbot membalas:

🚫 Jangan chat saya dulu, sedang sibuk bro 😴

`.pmmsg status`
- Menampilkan pesan penolakan PM yang sedang digunakan.

`.pmmsg reset`
- Mengembalikan pesan default:

🚫 PM DITOLAK

Pesan custom harus disimpan di database agar tidak hilang setelah restart.

FITUR 2 — TAG REPLY KHUSUS GRUP
════════════════════════════

Buat command:

.tagreply on
.tagreply off
.tagreply set <pesan>
.tagreply status
.tagreply reset

Fungsi:

`.tagreply on`
- Mengaktifkan auto-reply ketika Userbot di-mention/tag.

`.tagreply off`
- Mematikan fitur.

`.tagreply set <pesan>`
- User dapat menentukan sendiri kata-kata balasannya.

Contoh:

.tagreply set Ada apa manggil-manggil saya? 😂

Jika seseorang di grup mention Userbot:

@username bang

Userbot otomatis membalas:

Ada apa manggil-manggil saya? 😂


`.tagreply status`
- Menampilkan status ON/OFF dan pesan yang sedang digunakan.

`.tagreply reset`
- Mengembalikan pesan default Tag Reply.


ATURAN TAG REPLY:
- HANYA bekerja di grup/supergroup.
- Jangan bekerja di private chat.
- Deteksi mention username Userbot menggunakan Telegram message entity.
- Jangan membalas pesan yang tidak melakukan mention.
- Jangan membalas mention dari Userbot sendiri.
- Cegah spam/reply berulang jika orang melakukan mention berkali-kali.
- Setting ON/OFF dan pesan custom harus tersimpan setelah restart.
